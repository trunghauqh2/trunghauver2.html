Tài liệu thiết kế: Chợ sinh viên Sư phạm Huế

Bản mô phỏng phục vụ tiểu luận. Phạm vi nhỏ, chỉ dành cho sinh viên Trường Đại học Sư phạm Huế.

1. Quy trình nghiệp vụ

  1. Sinh viên đăng ký tài khoản (mã sinh viên, email trường).
  2. Gửi hồ sơ xác minh; quản trị viên duyệt tay, đối chiếu với dữ liệu sinh viên của trường. Duyệt tự động là hướng phát triển.
  3. Đăng bán và quản lý sản phẩm: tên, hình ảnh, giá, số lượng, trạng thái.
  4. Người mua tìm kiếm, lọc theo danh mục và nhắn tin với người bán.
  5. Hai bên tự thỏa thuận giá, tình trạng và địa điểm giao hàng trong khuôn viên trường. Web không giữ tiền.
  6. Khi cả hai bên cùng xác nhận, hệ thống ghi nhận giao dịch: số lượng giảm 1, người bán tăng một lượt bán thành công (uy tín).

4. Mã SQL (tạo bảng, dữ liệu mẫu, truy vấn uy tín)

-- Viết cho SQLite (đổi AUTOINCREMENT thành AUTO_INCREMENT nếu dùng MySQL)
PRAGMA foreign_keys = ON;

CREATE TABLE users (
  user_id INTEGER PRIMARY KEY AUTOINCREMENT,
  student_code TEXT NOT NULL UNIQUE,
  full_name TEXT NOT NULL,
  email TEXT NOT NULL UNIQUE,
  password_hash TEXT NOT NULL,
  role TEXT NOT NULL DEFAULT 'student' CHECK (role IN ('student','admin')),
  kyc_status TEXT NOT NULL DEFAULT 'chua_gui'
    CHECK (kyc_status IN ('chua_gui','cho_duyet','da_xac_minh','tu_choi')),
  created_at TEXT DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE kyc_requests (
  request_id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER NOT NULL REFERENCES users(user_id),
  card_image_path TEXT NOT NULL,
  face_image_path TEXT NOT NULL,
  status TEXT NOT NULL DEFAULT 'cho_duyet' CHECK (status IN ('cho_duyet','da_duyet','tu_choi')),
  reviewed_by INTEGER REFERENCES users(user_id),
  reviewed_at TEXT
);

CREATE TABLE categories (
  category_id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL UNIQUE
);

CREATE TABLE products (
  product_id INTEGER PRIMARY KEY AUTOINCREMENT,
  seller_id INTEGER NOT NULL REFERENCES users(user_id),
  category_id INTEGER NOT NULL REFERENCES categories(category_id),
  title TEXT NOT NULL,
  description TEXT,
  price INTEGER NOT NULL CHECK (price >= 0),
  quantity INTEGER NOT NULL DEFAULT 1 CHECK (quantity >= 0),
  image_url TEXT,
  pickup_location TEXT,
  status TEXT NOT NULL DEFAULT 'dang_ban' CHECK (status IN ('dang_ban','het_hang','da_an')),
  created_at TEXT DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE favorites (
  user_id INTEGER NOT NULL REFERENCES users(user_id),
  product_id INTEGER NOT NULL REFERENCES products(product_id),
  PRIMARY KEY (user_id, product_id)
);

CREATE TABLE conversations (
  conversation_id INTEGER PRIMARY KEY AUTOINCREMENT,
  product_id INTEGER NOT NULL REFERENCES products(product_id),
  buyer_id INTEGER NOT NULL REFERENCES users(user_id),
  created_at TEXT DEFAULT CURRENT_TIMESTAMP,
  UNIQUE (product_id, buyer_id)
);

CREATE TABLE messages (
  message_id INTEGER PRIMARY KEY AUTOINCREMENT,
  conversation_id INTEGER NOT NULL REFERENCES conversations(conversation_id),
  sender_id INTEGER NOT NULL REFERENCES users(user_id),
  content TEXT NOT NULL,
  sent_at TEXT DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE transactions (
  transaction_id INTEGER PRIMARY KEY AUTOINCREMENT,
  conversation_id INTEGER NOT NULL UNIQUE REFERENCES conversations(conversation_id),
  buyer_confirmed INTEGER NOT NULL DEFAULT 0,
  seller_confirmed INTEGER NOT NULL DEFAULT 0,
  status TEXT NOT NULL DEFAULT 'cho_xac_nhan' CHECK (status IN ('cho_xac_nhan','hoan_tat')),
  completed_at TEXT
);

-- Uy tín người bán = số giao dịch hoàn tất
SELECT p.seller_id, COUNT(*) AS so_lan_ban
FROM transactions t
JOIN conversations c ON c.conversation_id = t.conversation_id
JOIN products p ON p.product_id = c.product_id
WHERE t.status='hoan_tat'
GROUP BY p.seller_id;

5. Hạn chế và hướng phát triển

  • Phạm vi chỉ trong Trường Đại học Sư phạm Huế, không mở rộng toàn quốc để dễ kiểm soát.
  • Chưa có thanh toán trực tuyến; hai bên tự giao dịch. Có thể phát triển sau.
  • KYC hiện duyệt tay; có thể bổ sung duyệt tự động bằng cách đối chiếu với CSDL sinh viên.
  • Uy tín dựa trên số giao dịch hoàn tất nên có thể bị tăng ảo nếu hai người quen cùng xác nhận; cần cơ chế chống gian lận.
  • Bản web hiện là mô phỏng giao diện, dữ liệu chưa lưu vào CSDL thật.
